# Төрт топтау

**Төрт топтау** — қазақ тілі сабағына арналған сөздік ойыны. Алаңда 16 сөз бар, оларды мағынасына қарай
4 топқа бөлу керек. Ойын оқушылардың сөздік қорын, әсіресе сирек қолданылатын, дәстүрлі және
әдеби сөздерді меңгеруіне көмектеседі.

## Мүмкіндіктер

- 16 деңгей (Жеңіл / Орташа / Күрделі), 256 сөз, әр сөзге қысқаша қазақша түсіндірме
- 4×4 тақта, сөздер әр ойында араласады
- Тексеру: дұрыс топ жоғарыға түрлі түсті жолақ болып шығады, қате таңдау «Қайта көріңіз!» деп белгіленеді
  («бір сөз ғана қате» деген ескерту де бар)
- «Көмек» батырмасы: бір ойында 3 көмек, әрқайсысы бір сөзді және оның мағынасын ашады
- Ұпай, әрекет саны, табылған топтар, көмек саны, прогресс жолағы
- «Қайта бастау», «Жаңа ойын», ретімен немесе кездейсоқ деңгей таңдау
- Жеңіс экраны: ұпай, жұлдыздар және осы ойындағы барлық сөздердің сөздігі
- Прогресс браузерде (localStorage) сақталады, тіркелу мен сервер қажет емес
- Телефон, планшет, компьютер және интерактивті тақтада жұмыс істейді; пернетақтамен де ойнауға болады

## Жергілікті іске қосу

Қажет: [Node.js](https://nodejs.org/) 22.6 немесе жаңарақ.

```bash
npm install        # тәуелділіктерді орнату
npm run dev        # әзірлеу серверін іске қосу → http://localhost:5173
```

Басқа командалар:

| Команда            | Не істейді                                             |
| ------------------ | ------------------------------------------------------ |
| `npm run validate` | Сөздік қорын тексереді (4×4, қайталанбау, латын әрпі)  |
| `npm test`         | Барлық тесттерді (16 деңгейдің толық ойынын) өткізеді  |
| `npm run build`    | Тексеріп, `dist/` бумасына дайын сайтты жинайды        |
| `npm run preview`  | Жиналған сайтты жергілікті түрде көрсетеді             |

## Жаңа деңгей немесе сөз қосу

Барлық сөздер бір файлда: **`src/data/levels.ts`**. Файлдың басында үлгі бар.

1. `levels` тізімінің соңына жаңа деңгей қосыңыз: дәл 4 топ, әр топта дәл 4 сөз.
2. Әр сөзге `explanation` (қысқа түсіндірме) жазыңыз.
3. `npm run validate` командасымен тексеріңіз: қате болса, қай деңгейде екені көрсетіледі.

Компоненттердің кодын өзгертудің қажеті жоқ: жаңа деңгей автоматты түрде пайда болады.

## GitHub Pages-ке жариялау

Жобада дайын GitHub Actions workflow бар (`.github/workflows/deploy.yml`).

1. Кодты GitHub репозиторийіне жүктеңіз (`main` тармағы):
   ```bash
   git init
   git add .
   git commit -m "Төрт топтау"
   git branch -M main
   git remote add origin https://github.com/<USERNAME>/<REPO>.git
   git push -u origin main
   ```
2. Репозиторийде: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. **Actions** қойындысында workflow аяқталғанша күтіңіз (1–2 минут).
4. Сайт мына мекенжайда ашылады: `https://<USERNAME>.github.io/<REPO>/`

`main` тармағына әр push жасалғанда сайт автоматты түрде жаңарады.

**Техникалық ескерту:** `vite.config.ts` ішінде `base: './'` орнатылған, сондықтан репозиторийдің атауы
қандай болса да, сайт дұрыс ашылады. Ойын бір беттен тұрады (маршрутизация жоқ), ал workflow
`404.html` көшірмесін жасайды, сондықтан бетті жаңартқанда да қате шықпайды.
